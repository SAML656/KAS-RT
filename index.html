📖 Panduan Kas RT 01 / RW 02

Aplikasi ini membuat keuangan kas RT transparan. Warga bisa melihat uang masuk & keluar, mengunduh laporan, dan menyampaikan usulan tanpa perlu login.
🏠 1. Beranda – ringkasan kas
Menampilkan saldo kas, total uang masuk, total uang keluar, pengeluaran per kegiatan, dan transaksi terbaru.
  • Klik tab Beranda di menu kiri (atau menu bawah di HP).
  • Angka merah = uang keluar, hijau = uang masuk.
📒 2. Buku Kas – semua transaksi
Daftar lengkap seluruh transaksi kas RT.
  1. Buka tab Buku Kas.
  2. Gunakan kolom pencarian untuk mencari uraian atau nama pihak.
  3. Pakai filter jenis (masuk/keluar) atau kegiatan untuk mempersempit daftar.
Warga hanya dapat melihat. Tombol tambah, ubah, dan hapus transaksi hanya muncul untuk admin.
🗂️ 3. Arsip – folder & berkas rekap
Laporan dikelompokkan seperti folder di komputer: Iuran Warga, Operasional RT, Kebersihan & Keamanan, Pembangunan, Sosial, Liburan, Karnaval.
  1. Buka tab Arsip.
  2. Klik panah ▶ di panel kiri untuk membuka folder, lalu klik berkas rekap berdasarkan periode (mis. "Oktober 2026").
  3. Berkas terbaru selalu berada di paling atas. Lencana Draf = masih berjalan, Final = sudah disahkan/dikunci.
⬇️ 4. Mengunduh laporan (Excel)
  • Per berkas: klik tombol Unduh .xlsx pada berkas yang diinginkan (di daftar berkas atau di dalam berkas).
  • Berkas yang sudah diunduh ditandai ✓ Terunduh agar Anda tahu mana yang sudah dimiliki.
  • Semua kegiatan: menu Ekspor di kanan atas → Rekap Semua Kegiatan (ringkasan) atau Seluruh Buku Kas (semua transaksi).
  • Cetak / PDF: menu Ekspor → Cetak Laporan / PDF, lalu pilih "Simpan sebagai PDF".
💬 5. Usulan – sampaikan aspirasi
  1. Buka tab Usulan, klik Sampaikan Usulan.
  2. Isi judul usulan, nama Anda, dan rincian, lalu kirim.
  3. Pantau status: Sedang Ditinjau → Telah Dianggarkan atau Ditolak, beserta tanggapan resmi pengurus RT di bawah usulan.
Usulan terlihat oleh semua warga. Jangan menulis data pribadi sensitif (nomor HP, NIK, dll).
🎨 6. Tema & tampilan
Tombol Tema di kanan atas mengganti suasana warna: Teduh (nyaman di mata) atau Hijau Segar. Pilihan tersimpan di browser Anda. Aplikasi juga dapat dipakai di HP.
❓ 7. Pertanyaan umum
  • Data kosong? Berarti pengurus belum mencatat transaksi.
  • Angka tidak cocok? Hubungi pengurus melalui menu Usulan.
  • File Excel tidak terbuka? Buka dengan Microsoft Excel, LibreOffice, atau Google Sheets.
Mode Admin khusus pengurus RT (ketua, bendahara, sekretaris) untuk mencatat kas, mengelola berkas rekap, dan menanggapi usulan. Semua data tersimpan di database sehingga aman dan dapat dilihat semua warga.
🔐 1. Masuk, buat password & reset
Pertama kali:
  1. Klik tombol Admin pada pilihan Warga | Admin di kanan atas. Pertama kali, pilih "Belum punya password? Buat".
  2. Isi email pengurus yang terdaftar, buat password (min. 8 karakter), ulangi, lalu simpan.
  3. Catat Kode Pemulihan yang muncul. Kode hanya tampil sekali.
Berikutnya: masuk dengan email + password.
  • Ganti password: tombol Ganti Password di sidebar kiri bawah (saat mode admin aktif).
  • Lupa password: klik Lupa password?, isi email + kode pemulihan + password baru. Anda akan mendapat kode pemulihan baru.
  • Keluar: tombol Keluar Admin di sidebar. Selalu keluar bila memakai perangkat bersama.
Hanya email pengurus yang terdaftar di database yang bisa masuk. Jangan bagikan password atau kode pemulihan.
📝 2. Mencatat transaksi kas
  1. Buka Buku Kas → klik tombol catat/tambah transaksi, atau pakai Input Spreadsheet untuk banyak baris sekaligus.
  2. Pilih kegiatan/folder dan berkas rekap tujuan (opsional), isi tanggal, jenis (Masuk/Keluar), uraian, nominal, dan pihak/warga.
  3. Simpan. Data langsung masuk database dan tampil ke semua warga.
  4. Transaksi salah? Hapus lewat ikon hapus pada baris transaksi.
Berkas berstatus Final terkunci – transaksi tidak bisa ditambah. Buka kunci dulu bila perlu koreksi.
🗂️ 3. Membuat & mengelola berkas rekap (Arsip)
  1. Buka Arsip → pilih folder kegiatan → klik + Rekap Baru / Buat Berkas Rekap Baru.
  2. Isi judul (mis. "Rekap Iuran Warga – November 2026"), periode, status, dan deskripsi.
  3. Buka berkas untuk mengisi transaksi. Setelah laporan selesai dan diperiksa, klik 🔒 Kunci Final.
  4. Perlu koreksi? Klik 🔓 Buka Kunci Draf.
  5. Berkas salah/uji coba: klik Hapus Berkas (transaksi di dalamnya ikut terhapus – tidak bisa dibatalkan).
Satu berkas per periode (bulanan) menjaga arsip rapi. Daftar otomatis terurut dari yang terbaru.
⬆️ 4. Impor data dari Excel (.xlsx)
  1. Buka berkas rekap tujuan → klik Impor XLSX.
  2. Pilih file Excel dengan kolom: Tanggal, Jenis (Masuk/Keluar), Keterangan, Nominal, Pihak. Tanggal format 2026-10-05 atau 05/10/2026; nominal berupa angka tanpa titik/koma.
  3. Periksa pratinjau, lalu klik Simpan Transaksi.
⬇️ 5. Mengunduh & mencetak laporan
Sama seperti warga: unduh per berkas lewat Unduh .xlsx (ditandai ✓ Terunduh), atau menu Ekspor untuk Rekap Semua Kegiatan, Seluruh Buku Kas, dan Cetak/PDF siap rapat.
💬 6. Menanggapi usulan warga
  1. Buka Usulan.
  2. Ubah Status: Sedang Ditinjau, Telah Dianggarkan, atau Ditolak.
  3. Tulis tanggapan resmi hasil musyawarah, lalu klik Simpan Tanggapan.
  4. Usulan tidak pantas atau spam dapat dihapus dengan tombol Hapus.
⚙️ 7. Tips & keamanan data
  • Data tersimpan di database MySQL; lakukan backup berkala (ekspor database lewat phpMyAdmin).
  • Pastikan MySQL & server aplikasi aktif saat dipakai.
  • Gunakan password yang kuat dan simpan kode pemulihan di tempat aman.
  • Cek kembali nominal sebelum mengunci berkas menjadi Final.
